🎯 Quiz Game — Interactive Learning Web Application

An engaging full-stack quiz platform that challenges users with randomized, difficulty-scaled questions across popular web technologies — delivering instant feedback, score tracking, and a fun, responsive experience.

🚀 Tech Stack

Backend
Django • Django REST Framework (DRF) • SQL Database • RESTful APIs

Frontend
React • Modern, Responsive UI • Real-time State Management

🔐 Key Features

Dynamic Question Generation
Generates 10 unique questions per topic: HTML, CSS, JavaScript, React
Balanced difficulty: 3 Easy • 4 Moderate • 3 Hard per category

Secure & Efficient Backend
REST API endpoints to fetch randomized question sets
Stores and processes user answers for accurate scoring

Interactive User Interface
Real-time feedback on each answer (correct/incorrect)
Live score calculation and final results display
Smooth animations and intuitive question navigation

Fully Responsive Design
Mobile-friendly layout that works beautifully on all devices
Clean, engaging visuals with focus on usability

Scalable & Clean Architecture
Well-organized React components and state handling
Optimized API communication for fast loading and seamless experience
Ready for future expansions (more topics, timers, leaderboards, etc.)
